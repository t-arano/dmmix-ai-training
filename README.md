# AIブーストカレッジ 初級研修 第1回

2026年11月9日の研修で使う参加者用の紙芝居教材です。

## 開き方

https://t-arano.github.io/dmmix-ai-training/

- 「次へ」「前へ」または左右矢印キーでスライドを進めます。
- 「デモへ」で練習パートの入口に移動します。
- 「練習資料を開く」で本文表示、コピー、TXT保存ができます。
- 「依頼文をコピー」してClaudeに貼り付けます。
- 「原文もまとめてコピー」を使うと、ファイル添付を省いて練習できます。
- ClaudeとGoogleドキュメントには、それぞれ利用するアカウントでログインしてください。

このサイト自体にはログイン機能はありません。URLを開ける人が閲覧できる公開教材です。検索エンジンにはインデックスしないよう指定していますが、アクセス制限ではありません。

講師の内部メモと進行ガイドは含めず、受講者名は担当業務名に置き換えています。練習資料は架空のものです。

## ファイル

- index.html: 35枚のスライドと6点の教材を収録。単体でも使用できます。
- .nojekyll: GitHub PagesでHTMLをそのまま配信するための設定。
- robots.txt: 検索エンジン向けの設定。

操作内容を外部へ送信する機能やアクセス解析は含めていません。Claudeへのファイル添付・貼り付け・送信は利用者が操作します。
